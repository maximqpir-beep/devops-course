# Git и SVN

## 1. Почему ветки Git считаются дешёвыми?
Ветка Git — небольшая ссылка на коммит. Создать её можно локально, без копирования всех файлов и без подключения к серверу. У SVN ветка обычно оформляется копированием каталога в пространстве репозитория. При этом серверное копирование SVN тоже является дешёвым (cheap copy): физически все данные не дублируются. Поэтому утверждение «ветка SVN обязательно медленная и дорогая» неточно. Отличаются прежде всего модель работы, необходимость доступа к центральному репозиторию и организация слияний.

## 2. Можно ли сделать коммит SVN без интернета?
Для коммита требуется доступ к репозиторию SVN. Если центральный сервер недоступен, локальные изменения можно сохранить в рабочей копии, но зафиксировать их в истории сервера нельзя. Интернет как таковой не обязателен: репозиторий может находиться в локальной сети или на том же компьютере. Git позволяет делать локальные коммиты без доступа к удалённому серверу.

## 3. Когда SVN может быть предпочтительнее?
- Поддержка проекта с существующими процессами, интеграциями и большой историей SVN, когда миграция не оправдана.
- Требование централизованного управления и прав доступа к отдельным каталогам.
- Работа с плохо сливаемыми двоичными файлами в процессе, построенном на блокировках файлов.
