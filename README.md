Для завершения сдачи необходимо показать SSH и работу в VS Code на компьютере студента, настроить зеркало и подтвердить одну отправку в оба репозитория. Скриншоты промежуточных состояний (конфликт, история до rebase, reflog) нужно снять при локальном выполнении соответствующих упражнений.

История опубликована из локального прогона через GitHub API, поэтому хеши опубликованных коммитов отличаются от локальных. Ссылки на исходные коммиты в сообщениях cherry-pick/revert относятся к локальной истории, сохранённой в комплекте практик.

## Бонус: commit-msg hook

После основных упражнений можно включить проверку Conventional Commits:

```bash
git config core.hooksPath .githooks
```

Учебные сообщения `wip`, `oops` и стандартный `Revert` этот hook не принимает, поэтому включать его следует после соответствующих упражнений. SSH-ключи, отчёты, скриншоты и служебные логи в репозиторий не включены.
