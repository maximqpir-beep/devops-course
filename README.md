## Ветки

- `main`: основной результат; калькулятор содержит add, subtract и IMPORTANT_FIX.
- `feature/hobby-project`: описание пет-проекта для PR и настоящего code review.
- `feature/calculator`: три чистых коммита калькулятора.
- `hotfix/urgent-fix`: исправление и экспериментальные multiply/divide. В main перенесено только исправление.
- `prep/kr-practice`: ответы на три вопроса, объединённые в один коммит.

`feature_a.md` относится к сравнению merge/rebase, `test_hook.txt` — к проверке commit-msg hook. Домашняя ветка `practice/rebase-playground` остаётся локальной согласно заданию.

## Статус выполнения

Подготовлены файлы и перенесены результаты локальных Git-упражнений. Для завершения сдачи необходимо показать SSH и работу в VS Code на компьютере студента, пройти взаимное PR-ревью с исправлением замечания и Squash and merge, настроить зеркало и подтвердить одну отправку в оба репозитория. Скриншоты этих действий снимаются при выполнении.

История опубликована из локального прогона через GitHub API, поэтому хеши опубликованных коммитов отличаются от локальных. Ссылки на исходные коммиты в сообщениях cherry-pick/revert относятся к локальной истории, сохранённой в комплекте практик.

## Бонус: commit-msg hook

После основных упражнений можно включить проверку Conventional Commits:

```bash
git config core.hooksPath .githooks
```

Учебные сообщения `wip`, `oops` и стандартный `Revert` этот hook не принимает, поэтому включать его следует после соответствующих упражнений. SSH-ключи, отчёты, скриншоты и служебные логи в репозиторий не включены.
