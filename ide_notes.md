# Git в VS Code и терминале

## Три удобные возможности VS Code
1. Source Control показывает изменённые файлы в одном месте; перед коммитом удобно проверить состав изменений.
2. Diff рядом отображает старую и новую версии, поэтому проще заметить случайное изменение строки.
3. GitLens показывает автора и историю изменения строк без отдельного вызова git blame.

## Что удобнее в терминале
Interactive rebase: список коммитов и действия reword, squash, fixup и drop можно задать явно и затем проверить результат через git log.

Проверена отправка изменений в основной репозиторий и зеркало.
