# Цели на семестр

1. Освоить ветки, Pull Request, разрешение конфликтов и rebase; выполнить практические работы по Git с воспроизводимой историей.
2. Подготовить Dockerfile для Python-приложения, собрать образ и запустить приложение в контейнере.
3. Настроить CI в GitHub Actions: запускать тесты при push и Pull Request и блокировать принятие изменений при ошибках проверки.
