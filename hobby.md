# Мой пет-проект

## Идея
Консольный трекер учебных задач: добавлять задания, указывать срок сдачи, отмечать выполнение и просматривать незавершённые задачи.

## Стек
Python, SQLite, pytest, GitHub Actions; в дальнейшем Docker.

## Цель
Научиться хранить данные в базе, покрывать функции тестами и автоматически проверять изменения в CI.

## Минимальная версия
- Добавление задачи с названием и сроком.
- Список задач и отметка о выполнении.
- Сохранение данных между запусками.
